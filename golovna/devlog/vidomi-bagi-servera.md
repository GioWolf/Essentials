# Відомі баги сервера

<details>

<summary>Хибне спрацювання PvP режиму</summary>

**Зафіксовано два види хибного спрацювання входу в режим PvP.**

1. У PvE зоні на спавні сервера
2. При кидку Перлини Енду

<mark style="color:green;">**Вирішення проблеми:**</mark> тимчасово відсутнє (⇀‸↼‶)

</details>

<details>

<summary>Некоректне відображення капчі</summary>

**Бувають випадки, коли при перевірці бот-фільтра капча виходить за межі мапи.**

<mark style="color:green;">**Вирішення проблеми:**</mark>

* Варіант 1. Перезайдіть на сервер.
* Варіант 2. Використовуйте ліцензійну версію гри (ліцензійні акаунти не проходять перевірку).

</details>

<details>

<summary>Не відображаються скіни з піратської версії Java Edition</summary>

**Бувають випадки, коли скіни з піратської версії Java Edition не відображаються.**

<mark style="color:green;">**Вирішення проблеми:**</mark>

* Варіант 1. У налаштуваннях вашого лаунчера вимкніть кастомну систему скінів (наприклад, Ely.by).
* Варіант 2. Спробуйте підключитися до сервера з іншого лаунчера.
* Варіант 3. Купіть ліцензію гри та підключіться з офіційного лаунчера.

</details>

<details>

<summary>Не відображаються скіни та голограми з версії Bedrock Edition</summary>

**Якщо ви граєте з версії Bedrock Edition, скоріш за все, у вас некоректно відображаються скіни гравців, меню та голограми.**

<mark style="color:green;">**Вирішення проблеми:**</mark> Використовуйте [PojavLauncher](https://pojavlauncher.app/) для гри з мобільних пристроїв.

</details>
