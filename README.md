# Про сервер

### **TeamCube** – один з українських серверів Minecraft.

#### Сервер створений з метою отримання задоволення як для творця, так і для гравців. Він постійно розвивається, отримує нові оновлення та підтримку останніх версій гри.



### Як зайти на сервер ?

Для гравців **Java Edition**

{% stepper %}
{% step %}
### Завантажте актуальну версію гри

Інформація в нашому [телеграм](golovna/markdown.md) каналі.
{% endstep %}

{% step %}
### Додайте айпі адресу у список серверів

Айпі сервера `teamcube.hopto.org` або `193.19.252.97`
{% endstep %}

{% step %}
### Зайдіть на сервер

Насолоджуйтесь грою.
{% endstep %}
{% endstepper %}

Для гравців **Bedrock Edition**

{% stepper %}
{% step %}
### Завантажте перевірену версію Bedrock Edition

Перевірена версія в нашому [телеграм](https://t.me/TeamCube/71) каналі.
{% endstep %}

{% step %}
### Увійдіть в акаунт Xbox Live

Вам не потрібна ліцензія Bedrock Edition.
{% endstep %}

{% step %}
### Додайте айпі адресу та порт у список серверів

Айпі сервера `teamcube.hopto.org` або `193.19.252.97` порт `19132`
{% endstep %}

{% step %}
### Зайдіть на сервер

Насолоджуйтесь грою.
{% endstep %}
{% endstepper %}
